# 대시보드 기능 테스트 시나리오

대상: `/dashboard` (실시간 운항 대시보드). 명세는 `docs/specs/DASHBOARD.md`, 알려진 함정은 `docs/specs/KNOWN_PITFALLS.md` 2장을 참조한다.

**범위**: L1~L4 전체 구현 완료(11장 외부 API 연동 + 10장 딥링크 · 6.4·9.11장 제안속도 전송 · 4.1장 자동 새로고침). 미구현 항목 없음.

**사전 조건(모든 시나리오 공통)**
1. `npm run dev` 로 앱을 띄운다.
2. `/login` 에서 `admin@knotsofas.kr` / `demo` (또는 다른 데모 계정)로 로그인한다.
3. `/dashboard` 로 진입한다. 별도 언급이 없으면 필터는 아무것도 켜지지 않은 기본 상태에서 시작한다.
