## 1. 기본 — 스펙을 통째로
가장 단순한 화면입니다. 한 번에 시키면 됩니다.

docs/specs/ADMIN_USERS.md 를 처음부터 끝까지 읽고 사용자 관리 화면을 만들어줘.
src/app/(main)/admin/users/page.tsx 에 만든다.

범위:
- 4장 화면 구성 (헤더 / 역할별 요약 카드 4장 / 검색·역할 필터 / 목록 테이블 6열)
- 5장 로직 (필터링 · 인원 집계 · 배정 선박 변환 · 활성 토글)

주의:
- "사용자 추가" 버튼은 원본에 클릭 핸들러가 없다. UI만 만들고 동작은 비워둬라(의도된 미구현).
- 배정 선박 변환 시 filter(Boolean)을 반드시 넣어라.
  없으면 선박 목록에 없는 id가 섞였을 때 "KSF VENTURE, undefined" 처럼 표시된다.
- 요약 카드의 인원 수는 검색·필터와 무관하게 항상 전체 기준으로 센다.
- 부서는 '-'(ASCII 하이픈), 배정 선박은 '—'(em-dash)로 대시 문자가 다르다. 원본 그대로다.
- 비활성 행은 <tr> 전체에 opacity-50을 준다.

역할별 색·아이콘 4종은 요약 카드와 목록 배지가 공유하므로 상수로 한 번만 정의해라.

다 만들면 9장 재구현 체크리스트 14항목으로 누락을 확인해줘.

## 이 화면의 함정
거의 없습니다. 주의할 것은 명세에 이미 다 적혀 있고, 대부분 "원본이 그런 상태" 입니다.


| 의문 | 답 |
| --- | --- |
| "사용자 추가" 버튼이 동작하지 않음 | 정상. 원본에 핸들러가 없다 |
| 빈 결과일 때 안내 문구가 없음 | 정상. 헤더만 남은 빈 표가 원본 동작 |
| 대문자로 검색하면 안 걸림 | 정상. 대소문자 구분 부분 문자열 |
| 역할 배지 색이 로그인 화면과 미묘하게 다름 | 정상. 다크 모드 투명도가 /30 vs /40 |


개선하고 싶다면 빈 결과 안내(colSpan={6})와 등록 모달을 추가해도 됩니다. 다만 원본과 100% 동일하게 가려면 그대로 두세요.
