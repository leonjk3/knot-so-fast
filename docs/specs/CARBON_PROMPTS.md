## 1. 기본 — 스펙을 통째로
한 번에 시켜도 되지만, 블록이 많아 2단계로 나누는 편이 확인하기 쉽습니다.

docs/specs/CARBON.md 를 읽고 탄소 배출 리포트 화면의 앞부분을 만들어줘.
src/app/(main)/carbon/page.tsx 부터 시작한다.

이번 범위 (4장 기준 블록 0~5):
- 항차 선택 select
- 5장 계산 로직 전부 (5.1~5.4가 이후 모든 블록의 기초다)
- 스탯 카드 4종 + Scope 3 카드
- CII 등급 게이지 / CII 월별 추이 차트 / CII 시뮬레이터
- 대기 탄소 vs 운항 탄소 (차트 + 표)
- 3원 비교 분석 표

주의:
- 5.3장의 배수 4개를 혼동하지 마라. CII 점수용(1.0711/1.1378)과
  연료·CO₂용(1.1048/1.2145)이 서로 다르다.
- 차트는 ssr:false 동적 import + notMerge.
- CII 추이 차트의 yAxis에 scale: true 를 반드시 넣어라.
  끄면 0부터 그려져 7개월간 18% 개선이 거의 평평하게 보인다.
- 대기 탄소 표의 모든 수치에 toFixed(2)를 적용해라.

완료 확인 — 항차를 바꾸면 모든 수치가 함께 바뀐다. CII 추이 차트가 우하향한다.

이어서 나머지 블록(4장 기준 6~7)을 만들어줘.

- 재미 요소 3종(나무/자동차/치킨) + 에코 랭킹
- 탄소 절약 캔 + 배지 4종
- 7장 Scope 3 인증서 모달 (ko/en 본문 + .txt 다운로드)

전부 5.4장의 scope3SavedTon / scope3SavedPct 하나에서 파생된다.
값을 여러 곳에서 따로 계산하지 말고 한 번 구해 재사용해라.

다 만들면 12장 재구현 체크리스트 23항목으로 누락을 확인해줘.

완료 확인 — 캔이 약 17.7%까지 차오르고, 배지는 1·2번만 해금된 상태다.
