
# 대시보드 실행 프롬프트 (2단계용)
DASHBOARD.md의 L1~L4 단계를 그대로 복사해 쓸 수 있는 프롬프트로 풀어놓은 것입니다. DASHBOARD.md와 나란히 놓고 위에서부터 순서대로 실행하세요.

이 문서는 전달 수단, DASHBOARD.md가 내용입니다. 프롬프트는 명세의 어느 장을 읽으라고 가리킬 뿐이며, 실제 구현 기준은 항상 DASHBOARD.md 쪽입니다.

전제: BOOTSTRAP_PROMPTS.md 의 1단계가 끝나 있어야 합니다 (로그인 후 사이드바가 뜨는 상태). 이 문서는 대시보드 담당자 한 명이 사용합니다.

왜 대시보드만 별도 프롬프트가 있는가: 원본 코드 약 2,000줄로 7개 화면 중 가장 크고, 지도 관련 함정만 KNOWN_PITFALLS.md 에 9건입니다. 한 번에 시키면 품질이 떨어져 단계를 쪼갰습니다. 나머지 화면은 스펙 하나를 통째로 주고 재구현 체크리스트로 확인하는 것으로 충분합니다.



## 단계별 지도

| 단계 | 프롬프트 | 산출물 | 누적 상태 |
| --- | --- | --- | --- |
| L1 | 1-1 ~ 1-4 | 요약 카드 + 지도 + 선박·항로 | 여기까지만 해도 화면이 성립 |
| L2 | 2-1 ~ 2-2 | 함대 게이지 + 필터 | 데모의 핵심 인터랙션 |
| L3 | 3-1 ~ 3-3 | 항구·오버레이·리스트·범례 | 밀도 |
| L4 | 4-1 ~ 4-2 | 실시간 API · 딥링크 | 외부 의존 |


시간이 부족하면 L2까지만 하고 다른 화면을 도우세요. L3·L4는 없어도 데모가 성립합니다.

## 1-3. 지도 뼈대 — 초기화·타일·이음매
명세: DASHBOARD.md 9.1~9.5 · 소요 30분 · 이 단계가 가장 함정이 많다

docs/specs/DASHBOARD.md 9.1장부터 9.5장까지 읽고 MapView 컴포넌트의 뼈대를 만들어줘.
아직 마커는 그리지 않는다. 지도가 뜨고 패닝·줌이 되는 것까지가 목표다.

반드시 지킬 것:
1. (9.1) dynamic(() => import(...), { ssr: false }) 로 로드한다.
   Leaflet 모듈도 useEffect 안에서 await import('leaflet') 한다.
   StrictMode 이중 실행을 막는 active 플래그를 둔다.
2. (9.2) 이음매 SEAM_LNG = -30, MAX_LAT = 85.0511287798.
   wrapLng()와 wrapRouteSegments()를 명세의 의사코드대로 정확히 구현한다.
   ±90을 쓰면 Web Mercator가 발산해 지도가 잘린다.
3. (9.3) maxZoom 15, worldCopyJump false, zoomAnimationThreshold 20.
   최소 줌은 "가로 폭 기준으로만" 계산하고, requestAnimationFrame과 resize에서 재계산한다.
   세로까지 맞추면 화면 비율에 따라 좌우가 잘린다.
4. (9.4) 타일 레이어에 bounds 옵션을 절대 주지 마라.
   이음매를 옮겼기 때문에 랩핑된 타일 좌표가 재정규화되어 태평양이 회색으로 빠진다.
   해도(OpenSeaMap) maxZoom 12를 반드시 지정한다 — 이 서버는 지원 범위를 넘는 줌에서
   HTTP 오류가 아니라 "Zoom Level not supported" 문구가 그려진 이미지를 200으로 반환해서
   errorTileUrl로는 걸러지지 않는다.
5. (9.5) LayerGroup 3개(voyage/port/overlay)와 커스텀 pane weatherPane(z-index 400,
   pointer-events none)을 만들어둔다.
6. 지도 컨테이너에 className="w-full h-full"(퍼센트)을 쓰지 마라. 부모가 flex-1로 실제
   픽셀 높이를 가져도 그 부모의 CSS height 속성은 여전히 auto라 퍼센트가 해석되지 않고,
   Leaflet 내부 pane은 전부 position:absolute라 auto-height 계산에도 안 잡혀 컨테이너가
   0px로 접힌다. 콘솔 에러도 없고 타일 요청도 200이라 원인을 찾기 어렵다. 부모에 relative,
   지도 컨테이너에는 absolute inset-0을 써라(KNOWN_PITFALLS.md 2.10).

cleanup에서 map.remove()와 모든 ref 정리를 잊지 마라.

완료 확인 — 지도가 뜨고, 좌측 끝이 유럽/아프리카다. 최대로 축소해도 세계지도가 한 벌만 보인다. 확대해도 Zoom Level not supported 문구가 안 보인다. 콘솔에 에러가 없다고 안심하지 말고, 실제로 화면에 타일이 채워져 보이는지 눈으로 확인한다.

- effect 의존성은 [mapReady, focusTarget?.token] 뿐이다.
  좌표를 넣으면 같은 지점을 다시 클릭했을 때 반응하지 않는다.
- direct면 setView({animate:true}), 아니면 flyTo({duration:0.8}).
  필터 리셋처럼 줌 델타가 큰 이동에 flyTo를 쓰면 "제자리 줌아웃 → 이동" 두 단계로 보인다.
- marker가 있으면 map.once('moveend')에서 해당 마커 팝업을 연다.

[리스트 패널 8장]
- "이슈" 또는 "항구" 필터가 켜져 있을 때만 컨테이너를 렌더링한다(빈 공백을 남기지 마라).
- 이슈 목록 + 위험구역 목록, 항구 현황 목록. max-h-28 overflow-y-auto.
- 클릭 시 지도 이동: 이슈 줌 6(팝업 열기), 위험구역 줌 6, 항구 줌 9(팝업 열기)
- 각 헤더의 "요약" 버튼 → 8.3장 모달 2종

함대 게이지 카드의 LocateFixed 버튼도 이제 연결한다(줌 8, 팝업 없음).

완료 확인 — 이슈를 클릭하면 지도가 이동하고 팝업까지 열린다. 같은 항목을 연속으로 클릭해도 매번 이동한다.

## 3-3. 지도 위 UI
명세: DASHBOARD.md 9.10 · 소요 20분

docs/specs/DASHBOARD.md 9.10장대로 지도 위 오버레이 UI 3종을 만들어줘.

1. 언어 선택기(상단 중앙) — ko/en/zh/ja 4개.
   지도 타일은 바뀌지 않는다. 팝업·툴팁 등 우리가 그리는 정보의 언어만 바꾼다.
   이를 위해 MAP_LABELS 사전(4개 언어)을 만든다 — 키 목록은 12장 끝에 있다.
2. 지도 유형(우상단) — 기본 지도 / 위성.
   레이어를 추가·제거하지 말고 기본 타일의 setUrl()만 교체한다.
3. 범례(좌하단) — 컨테이너 전체가 클릭 가능한 접기/펼치기. 기본값은 접힘.
   펼치면 상태색 4종 + 마커 형태 3종 + 오버레이 점선 3종.

모두 지도 컨테이너에 absolute + z-10으로 얹는다.

완료 확인 — 언어를 바꾸면 선박 팝업의 라벨이 바뀐다. 범례 아무 곳이나 눌러도 접힌다.



# L4 — 선택

## 4-1. 외부 API 연동
명세: DASHBOARD.md 11장 · 소요 30분

docs/specs/DASHBOARD.md 11장대로 외부 API를 붙여줘. 전부 실패해도 화면이 동작해야 한다.

1. (11.1) Open-Meteo 기상 8지점 — API 키 불필요, 브라우저에서 직접 호출.
   Promise.allSettled로 일부 실패를 허용하고 성공한 지점만 표시한다. 타임아웃 8초.
2. (11.2) GDACS 태풍 — CORS 때문에 /api/typhoons Route Handler를 경유한다.
   XML 파싱 시 속성명은 units가 아니라 unit(단수)이고, 값은 텍스트 노드가 아니라
   value 속성에 있다. 이 한 글자 때문에 태풍이 전혀 표시되지 않은 적이 있다.
   클라이언트는 실시간 데이터와 MOCK_TYPHOONS를 병합한다 —
   실제 태풍이 기본 뷰포트 밖(동태평양)에 있으면 화면이 비기 때문이다.
   15분마다 재조회, 실패 시 mock만 사용.
3. (11.3) RainViewer 강수 레이더 — maxZoom 10 고정. 실패는 조용히 무시.

각 훅의 cleanup에서 cancelled 플래그를 세워라.

완료 확인 — 기상 카드가 지도에 뜬다. 네트워크를 끊어도 화면이 깨지지 않고 mock으로 동작한다.

## 4-2. 딥링크·자동 새로고침·제안속도 전송
명세: DASHBOARD.md 4.1 · 6.4 · 9.11 · 10장 · 소요 25분

docs/specs/DASHBOARD.md 의 아래 항목을 마저 붙여줘.

1. (10장) 딥링크 3종 — sessionStorage 1회성 키 + router.push
   - 게이지 카드 AI 버튼 → 'ksf:ai-report-vessel-id' → /ai-report
   - 주간 캘린더 날짜   → 'ksf:schedule-calendar-date' → /schedule
   - 에코 랭킹 항목     → 'ksf:carbon-vessel-id' → /carbon
   받는 쪽이 아직 없어도 상관없다. 키 이름을 정확히 맞춰라.
2. (6.4) 제안속도 전송 — POST /api/vessel-commands/speed-recommendation
   서버는 실제 전송 없이 900~1400ms 지연 후 성공 응답을 주는 데모용 시뮬레이션이다.
   전송 중인 선박 id를 Set으로 관리해 버튼별 개별 로딩을 표시한다.
3. (9.11) 지도 팝업의 전송 버튼 — 팝업은 React 트리 밖의 raw HTML이라
   onClick을 붙일 수 없다. map.on('popupopen')에서 data 속성으로 대상을 찾아 위임한다.
4. (4.1) 자동 새로고침 — 아이콘이 왼쪽으로 밀리며 select가 펼쳐지는 애니메이션.
   주기 설정 중에는 아이콘이 빨간색으로 3초 주기 회전.

완료 확인 — AI 버튼을 누르면 /ai-report로 이동한다(화면이 없으면 404여도 무방). 제안속도 전송 시 alert에 선박명·항로·속도가 표시된다.
