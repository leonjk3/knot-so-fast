## 1. 기본 — 스펙을 통째로
이 화면은 한 번에 시켜도 품질이 나옵니다. 아래 프롬프트 하나로 시작하세요.

docs/specs/SIMULATION.md 를 처음부터 끝까지 읽고 물류 시뮬레이션 화면을 만들어줘.
src/app/(main)/simulation/page.tsx 부터 시작한다.

범위:
- 4장 화면 구성 (좌 조건 폼 / 우 결과 카드 4장)
- 5장 계산 로직 전부
- 6장 차트 2종 (비교 막대 · 속도 커브)

7장 PDF 내보내기는 나중에 별도로 요청하겠다. 버튼만 만들고 비워둬라.

반드시 지킬 것:
- 5.2장 초안/적용 분리. 모든 결과·차트는 applied만 참조한다.
  예외는 4.8장의 번잡도·선석 힌트 2개뿐이며, 이건 초안 기준으로 즉시 갱신돼야 한다.
- 5.3장 연료 모델은 이 화면 전용이다. 선박의 fuelCurve를 쓰지 마라.
  baseFuelPerDay 140 고정 + 속도³ 비례 + 흘수 보정이다.
  그래서 같은 항차라도 다른 화면과 값이 다른 것이 정상이다.
- 6.2장 속도 커브의 x축은 value 타입이어야 한다. category로 하면 markLine 좌표 지정이 안 된다.

다 만들면 11장 재구현 체크리스트로 누락을 확인해줘.

완료 확인 — 슬라이더를 움직이면 "조건이 변경되었습니다" 힌트가 뜨고, 실행 버튼을 눌러야만 우측 결과가 바뀐다. 속도 커브에 계획 속도(호박)와 시뮬 속도(에메랄드) 두 마커가 보인다.
